Before you start

Build the test lab

Most tests run in a flat creative world, where a single habitat block gives predictable results. Test 8 repeats the checks in a normal world.

Updated 18 Oct: habitat crash fixed

The first build of v2.0 crashed the game near habitat blocks. Use the newly built zips. If a world crashed with the old ones, take the SpawnFilter zips out of saves/<world name>/datapacks/ before opening it again, then copy in the new zips.

Updated 19 Oct: Test 6 lab spots fixed

The herds in Test 6 could never spawn at the old open field or covered room, because of conditions built into base Cobblemon. The packs were fine. If your lab world already exists, run the two build commands under Three lab spots, then redo Test 6.

Create the lab world

  1. Create a new world: Game Mode Creative, Allow Commands On, World Type Superflat (the default "Classic Flat" preset, which is all Plains).
  2. Close the game to the title screen, then copy all nine .zip files from the SpawnFilter_Gen#_Cobblemon1.8.2_v2.0 folders into saves/<world name>/datapacks/.
  3. Open the world again. The ground surface is at Y −61, so you stand at Y −60.

Freeze the world so results stay readable

/gamerule doDaylightCycle false
/time set noon
/gamerule doWeatherCycle false
/weather clear
/gamerule doMobSpawning false
/gamerule doPokemonSpawning false

doPokemonSpawning false stops Pokémon from piling up on their own. /checkspawn and /forcespawn still work. If /forcespawn keeps saying it can't spawn anything somewhere it should, turn this gamerule back on for that test.

Confirm the packs and their marker tags loaded

Each pack ships a tag named spawnfilter:gen#_enabled that only exists while that pack is installed. The shared spawn rule reads these tags to know which generations you have.

/datapack list enabled
/locate biome #spawnfilter:gen1_enabled

Three lab spots

Keep tests apart so they can't affect each other. A habitat block only reaches about 16 blocks, so 200 blocks between spots is plenty.

SpotUsed forGo there
Habitat padTests 1–5: one habitat block under your feet/tp @s 0 -60 0
Open fieldRegular spawns, Eevee herds (needs a small concrete patch)/tp @s -200 -60 0
Dark roomZubat herds and Alpha Crobat (need a sealed, pitch-black room with a planks floor)/tp @s 200 -60 0

Build both once. The first lays a 3 × 3 concrete patch at the open field. The second builds a sealed oak-planks box around the dark room spot. If you built the older stone roof there, you can leave it.

/fill -201 -61 -1 -199 -61 1 minecraft:white_concrete
/fill 194 -61 -6 206 -56 6 minecraft:oak_planks hollow

These herds come with spawn presets in base Cobblemon. Eeveelution herds use urban, so they need concrete within 4 blocks. Zubat herds and Alpha Crobat use derelict, so they need no sky, light level 0, and a floor that isn't natural ground (grass, dirt, stone or sand). Without these builds, the herds don't spawn at all, even with no packs installed.

Your test tools

CommandWhat it does
/checkspawn <bucket>Lists what could spawn in an 8 × 16 × 8 block box around you, with chances. Buckets: common, uncommon, rare, ultra-rare, boss (Alphas). It uses the real spawner, so the filter rule applies to it.
/forcespawn <amount>Spawns Pokémon right now from the area around you (same as /spawnpokemonfrompool). Spawning stops once about 9 Pokémon are nearby, so clear them between runs.
/kill @e[type=cobblemon:pokemon,distance=..48]Clears wild Pokémon around you. Recall your own Pokémon first.
/data get entity @e[type=cobblemon:pokemon,sort=nearest,limit=1] PokemonShows the nearest Pokémon's data. Look for alolan, galarian or hisuian to confirm a regional form.
/tick sprint 24000Fast-forwards one in-game day of ticks. Habitats change which Pokémon they offer ("phases") once per day of ticks, and /time add does not change phases.
/datapack enable | disable "file/…zip"Turns packs on and off without leaving the world. Each test lists the exact commands.
Reading results

What passing looks like

The one rule behind every test: with a set of packs installed, every Pokémon that /checkspawn lists or /forcespawn creates must belong to an installed generation. Regional forms count as their region's generation (Alolan = Gen 7, Galarian and Hisuian = Gen 8, Paldean = Gen 9).

/checkspawn prints one line per Pokémon or herd. Regular and habitat spawns show the species name. Herds show their spawn ID instead, which is how you can see which herd version is active.

Spawns: Rattata: 41.3%, Pidgey: 35.2%, Spearow: 21.32%, eeveelution-herd-1__sf.in1.out2.out4.out6.: 2.1%, geodude-herd-1: 0.08%

Percent colors: green 5% and up, yellow under 5%, red under 0.1%, purple under 0.01%. Regional forms show their plain species name here ("Geodude"), so confirm the form on a spawned Pokémon.

Herd ID decoder

Herds that mix generations ship in one version per combination of installed generations. Paste a herd ID from /checkspawn to see which combination it is for.

Test 1

Baseline: no filter packs

Proves the test habitat works in plain Cobblemon, so later results mean something.

Turn every pack off

Place a Berry Patch habitat block at the pad

Go to the pad (/tp @s 0 -60 0), then run both commands. The first clears the spot; an error from it on the very first run is fine.

The block looks like moss. It uses the Berry Patch spawn list, replaces normal spawns within 16 blocks (like Cobblemon's own habitats) and steps through its phases in order, one per in-game day.

Check it

/checkspawn uncommon
/checkspawn common
Stop here if

/checkspawn shows ordinary Plains Pokémon or nothing at all. The habitat block didn't take effect, so later tests can't tell you anything. Re-run the two pad commands while standing at 0 -60 0, and report it if it still fails.

Test 4

Regional forms go to their region's generation

In habitats, the packs can see a Pokémon's species but not its form. A species that habitats only spawn in its regional form (the Alolan Geodude line, Hisuian Zorua) goes to the region's generation. A species that habitats spawn in both forms (Vulpix, Ponyta, Corsola and 32 others) only spawns from habitats when both generations are installed, so no other generation's form can slip in.

Test 6

Herds that mix generations

Each herd that mixes generations exists in several versions, and exactly one should be active for the installed generations. Herds with a single generation keep their usual IDs (for example rattata-herd-1) and behave as before.

6a · Eeveelution herd at the open field

eeveelution-herd-1 is an uncommon herd. It spawns under open sky in any overworld biome, on natural ground with concrete within 4 blocks (Cobblemon's urban preset). The open field's concrete patch covers this. The herd mixes Gen 1 (Eevee, Vaporeon, Jolteon, Flareon), Gen 2 (Espeon, Umbreon), Gen 4 (Leafeon, Glaceon) and Gen 6 (Sylveon).

If no eeveelution-herd-1 line shows for any row, check that the concrete patch is under you. The urban preset also blocks this herd inside villages, which the Classic Flat preset can generate. If a village sits on the open field, move to plain grass and lay the patch there.

Test 8

Real habitats in a normal world

Repeats the checks on habitats as Cobblemon generates them, with all their blocks and terrain.

Set up the field world

  1. Create a second creative world with commands on, World Type Default, and the same nine zips in its datapacks folder.
  2. Run the freeze commands from Setup, but leave doPokemonSpawning on if you want to watch natural spawns.

Find a habitat and stand in the middle of it

/locate structure #cobblemon:habitats/habitats
/locate structure cobblemon:habitats/berry_patch
/locate structure cobblemon:habitats/natural_lightningrod
/locate structure cobblemon:habitats/carved_ice_spikes

Click the green coordinates in chat to get a teleport command, or land safely on the surface with /spreadplayers <x> <z> 0 1 false @s. Habitat blocks look like ordinary blocks; press F3 and look for cobblemon:habitat_block as the targeted block to find them. In creative, right-clicking one opens its settings, so close that screen without changing anything.

Always compare against a baseline

Real habitats have many habitat blocks close together. Check each one first with every pack off (Test 1 commands), note what /checkspawn shows, then turn packs on. With packs, you should see that same list minus the generations you don't have. If the baseline itself shows little or nothing in the middle, try a spot nearer the edge.

Test 9

Fishing and server load

Fishing (unchanged from v1.0, worth one look)

Fishing still uses the per-generation spawn files; the new rule doesn't touch it. With Gen 1 only, fish a river or ocean a few times with a Poké Rod.

Lag check near habitats

With all nine packs on, stand in a real habitat with natural spawning on for a minute, then compare with every pack off.

/tick query
If something fails

What to capture

  • The test and check that failed, and the output of /datapack list enabled.
  • A screenshot of the /checkspawn output, plus where you were: the habitat's name (or pad pool), your coordinates (F3) and dimension.
  • Any lines in logs/latest.log mentioning spawnfilter, generation_filter, molang or Error.
  • Whether the same check passes with all packs off. If the baseline is also wrong, the issue is in Cobblemon itself rather than the packs.
