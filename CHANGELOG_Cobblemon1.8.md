# Modrinth changelogs: Cobblemon 1.8.2 update

Each pack is its own Modrinth project, so each section below is pasted into that pack's version changelog.
They all share the same layout. Only the "New Pokémon" and herd examples differ.

---

## Gen 1: Kanto

## Updated for Cobblemon 1.8.2
Built for **Cobblemon 1.8.2** (Minecraft 1.21.1). If you're still on Cobblemon 1.7.x, keep using the previous version of this datapack.

### Alpha Pokémon & herds
- Added Cobblemon 1.8's new **Alpha Pokémon** and **herd** spawns for Gen 1: 56 Alpha spawn files (60 different Alpha Pokémon) and 57 herd spawn files.
- Herds only contain Gen 1 Pokémon. Family members from other generations are left out. For example, Pikachu herds no longer include Pichu, and Zubat herds no longer include Crobat.
- Combining packs? Herds that mix generations go back to Cobblemon's originals when all their generations are installed. For example, Gen 1 + Gen 2 brings back the Crobat-led Zubat herds.

### Spawn changes
- All Gen 1 spawn rules now match Cobblemon 1.8.2: rebalanced spawn weights and biomes, plus the new Poké Snack-only spawns.
- No new Gen 1 Pokémon were added in this Cobblemon update.

### Habitat structures
- The new Habitat structures from Cobblemon 1.8 now only spawn Gen 1 Pokémon (or Pokémon from every generation you've installed, when combining packs).
- Habitats replace normal spawning right around them, so a habitat with none of your generations' Pokémon won't spawn anything nearby. 12 of the 51 habitat types have no Gen 1 Pokémon.
